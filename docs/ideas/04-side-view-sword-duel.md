# 04 — Side-view sword duel (Nidhogg-style)

You fight in 3D with your real body, but the screen shows it from the side, like Nidhogg. One or two players.

## Mapping 3D movement to the side view

- **Up / down** → sword height: high, middle or low guard (the core of Nidhogg)
- **Forward / back** (toward the TV) → thrust and pull back; a fast push forward = lunge
- **Sideways** → ignored, or used for a dodge or parry

## Mirroring for two players

Both players face the TV, but on screen the fighters face each other. The game mirrors one player: for P1 pushing forward attacks right, for P2 the same push attacks left. Both move naturally.

## Moving the character

The sword hand is busy, so walk with the thumbstick on the same controller, or by stepping / leaning if the Quest can see the body.

- Third-person 3D instead of side view
