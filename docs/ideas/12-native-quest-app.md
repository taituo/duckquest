# 12 — Native Quest app (APK)

Not yet: the web page is better for experimenting. Make an APK once the idea is proven.

## When it's worth it

- One tap to start; finds the computer by itself (no addresses or certificates)
- Runs more reliably in the background or starts automatically
- Easy to share as a finished thing

## What it takes

- Developer mode on the Quest (via the Meta Horizon app on the phone)
- Build in **Godot** or Unity with Meta's XR support. The code is small: read controllers, send over Wi-Fi like the web page.
- Install with a USB cable via SideQuest or adb
- Share on SideQuest
